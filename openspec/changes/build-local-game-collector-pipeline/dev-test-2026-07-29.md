## Defects found and fixed

1. Standard MinIO pre-signed PUT rejects an unsigned checksum metadata header. The Gateway now
   permits the standard PUT and recomputes SHA-256 from the private Inbox object when metadata is
   absent.
2. The standalone Consumer did not register all SQLAlchemy models, causing a dead letter while
   flushing `games.last_used_article_id`. A shared explicit ORM registry is now loaded at Consumer
   startup.
3. Heartbeats could overwrite the server-owned source allowlist. Heartbeats now preserve that
   allowlist and reject reported sources outside it.
4. CDN `Content-Type` could disagree with image bytes and fail the whole Bundle at the packaging
   boundary. The Collector now identifies supported images by signature and skips non-images.
5. The local self-signed Gateway certificate is not trusted automatically by the Collector or
   the in-app browser. The Collector requires `SSL_CERT_FILE` to point at the issued local CA/cert;
   browser verification used a temporary localhost HTTP listener that was closed afterward.

The first dead-letter transfer
`transport-28984cd585ece0c573ad3c6c` remains intact as failure evidence.
